# 가치커피 카페쇼 준비실

기획서(2026-10-03 초안), Google 준비 문서와 시트(2026-10-04 조회)를 반영한 공유 화면입니다.

## 포함된 기능

- 오늘 날짜와 담당자에 따른 우선 확인 작업
- 전체 일정 44개와 선행 작업, 대표 결정사항 8개, 발주·구매 20개
- 기획 의도, 관람객 흐름, 채택·후보·보류·폐기 구분
- 자료 간 충돌과 결정 누락 확인
- 작업별 Codex 도움 요청 복사
- 모바일 지원

## 현재 데이터 연결 범위

상태 기록은 원본 Google 시트에서 합니다. 웹페이지는 배포된 data.json을 60초마다 다시 읽지만 Google 시트의 변경을 직접 동기화하지는 않습니다. 팀원 공통 자료를 바꾸려면 원본을 조회하고 data.json을 갱신해 다시 배포해야 합니다. 브라우저별 로컬 상태를 팀 공용 상태로 표시하지 않습니다.

화면 안에서 AI가 자동 실행되거나 알림이 발송되지는 않습니다. 도움 요청 복사 후 Codex 채팅으로 보내면 해당 작업을 진행할 수 있습니다.

기획 톤·목표 우선순위·기한 충돌은 대표 확인 전까지 자동 확정하지 않습니다. 원본 상태는 대기이며 실제 미완료 여부는 확인이 필요합니다.

## GitHub Pages에 발행

이 폴더의 전체 파일을 사용하기로 정한 저장소에 넣습니다. 저장소 설정의 Pages에서 main 브랜치의 루트 폴더를 발행 대상으로 선택합니다. 기존 사이트가 있는 저장소라면 원본 파일을 덮어쓰지 말고 별도 경로를 선택해야 합니다.

GitHub Pages는 기본적으로 공개입니다. 검색 제외 메타 태그는 접근 통제가 아닙니다. 팀원 전용으로 운영할 경우 인증과 권한 확인을 추가하고, 비공개 자료를 공개 저장소에 포함하지 않아야 합니다. 개인정보·예산 상세·업체 연락처·GitHub 토큰은 이 배포 파일에 넣지 않습니다.

## 다음 연결 단계

공개 범위와 저장소를 결정한 뒤, 팀원 상태 기록을 위해 Google 시트 인증 연결 또는 별도 공용 저장소를 설정합니다. 실제 자동 갱신과 Codex 정기 확인은 해당 접근 권한 및 실행 연결이 마련된 뒤 활성화합니다.
